# Time | وقتي

مخطط يومي مجاني (عربي / English) يرتب مهامك تلقائياً على ساعات يومك.
Free bilingual daily planner that auto-schedules your tasks.

## Features
- Auto-schedule tasks by priority, with breaks
- Arabic (RTL) / English, dark mode
- Focus timer (25 / 50 min)
- Voice input
- Data stays in the browser (localStorage)

## Deploy
Static site: no build command, publish directory `.` (see `render.yaml`).
